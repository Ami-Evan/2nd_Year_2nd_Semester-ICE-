## Experiment E2-2: Compare Biased and Unbiased Estimators of Variance

### Theory

Variance measures how much the data values spread around the mean. When estimating population variance from a sample, two common estimators are used.

The **biased estimator** divides the sum of squared deviations by **n**. The **unbiased estimator** divides it by **n − 1**. The unbiased estimator is generally used for sample variance because its expected value is equal to the true population variance.

In this experiment, random samples are generated from a normal distribution with true variance **4**. Both estimators are calculated repeatedly for 1000 simulations and compared using a boxplot.

### Objectives

1. To understand biased and unbiased variance estimators.
2. To calculate variance using both **n** and **n − 1**.
3. To compare the two estimators through simulation.
4. To observe which estimator is closer to the true population variance.
5. To visualize the results using a boxplot.

### Pseudocode

```text
START

Set sample size n = 10
Set number of simulations = 1000
Set true variance = 4

Create arrays for biased and unbiased estimates

FOR i = 1 to 1000

    Generate a random sample of size 10
    from Normal distribution with mean 0
    and variance 4

    Calculate sample mean

    Calculate biased variance:
        Sum of squared deviations / n

    Calculate unbiased variance:
        Sum of squared deviations / (n - 1)

    Store both variance estimates

END FOR

Calculate average biased estimator
Calculate average unbiased estimator

Display:
    Average biased estimator
    Average unbiased estimator
    True variance

Create a boxplot for both estimators

Draw a horizontal line at true variance = 4

END
```
