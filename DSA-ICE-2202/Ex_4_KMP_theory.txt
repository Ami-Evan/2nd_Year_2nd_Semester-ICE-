## Theory

**Knuth-Morris-Pratt (KMP)** is a string matching algorithm used to find a given **pattern (word)** in a **text** efficiently.

In this program, the text is read from a `.txt` file. The user gives a word as the pattern, and the KMP algorithm searches for that word in the file.

KMP uses an **LPS (Longest Prefix which is also Suffix)** array. The LPS array helps the algorithm avoid comparing characters that have already been matched. Therefore, it is faster than the simple/brute-force pattern matching method.

**Time Complexity:** `O(n + m)`
where,

* `n` = length of the text
* `m` = length of the pattern

**Space Complexity:** `O(m)`

---

## Algorithm

1. **Start**
2. Open the text file using `ifstream`.
3. Check whether the file was opened successfully.
4. Read all the lines from the text file and store them in a string called `text`.
5. Take the search word/pattern as input from the user.
6. Create the **LPS array** for the given pattern:

   * Compare characters of the pattern.
   * If they match, increase the prefix length and store it in the LPS array.
   * If they do not match, use the previously calculated LPS value.
7. Set two pointers:

   * `i` for the text
   * `j` for the pattern
8. Compare `text[i]` with `pattern[j]`.
9. If they match, increase both `i` and `j`.
10. If the complete pattern is matched, print its position.
11. After finding a match, use the LPS array to continue searching for another occurrence.
12. If a mismatch occurs:

    * If `j != 0`, update `j` using the LPS array.
    * Otherwise, increase `i`.
13. Continue until the end of the text.
14. If no match is found, display **"Pattern not found!"**
15. **Stop**.
